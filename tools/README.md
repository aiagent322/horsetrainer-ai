# Rebuild order for the Q&A section
build_qa.py needs SUPABASE_KEY (anon key is enough) and regenerates every qa page from the `qa` table. It does NOT produce everything on the live pages, so run the rest after it:

1. `SUPABASE_KEY=... python3 build_qa.py`
2. `python3 tools/qa_videos.py inject`      – restores the 655 "Watch:" video blocks, their CSS and click-to-play script (data/qa_videos.json)
3. `python3 tools/sync_qa_lists.py`          – category pages list every answer page that exists; counts match
4. `python3 tools/dedupe_canonicals.py`      – duplicate cross-category answers canonicalize to one copy
5. `python3 tools/fix_meta_lengths.py`       – titles <= ~60, descriptions <= 160 (removal only)
6. `python3 tools/set_descriptions.py`       – hand-written descriptions for pages where the generic ones are too short
7. `python3 tools/add_og_tags.py` and `python3 tools/add_jsonld.py` (only if build_qa output lacks them)
8. `python3 tools/build_sitemaps.py`

If you add new videos to answer pages by hand, run `python3 tools/qa_videos.py extract` afterwards so a rebuild does not drop them.

## Video library pages (one page per video)
`python3 tools/build_video_pages.py` writes videos/watch/<slug>/ (one page per video), videos/library/ and videos/library/<category>/ from videos.json (oEmbed title + channel), data/qa_videos.json and the pages that use each video. Slugs are persisted in data/video_slugs.json so URLs do not change. Nothing is invented: channel shows only where videos.json has it, and there is no VideoObject markup because uploadDate is not known.
After a Q&A rebuild or new videos: build_qa.py -> qa_videos.py inject -> build_video_pages.py -> link_qa_videos.py (adds 'About this video' links; run qa_videos.py extract after) -> build_sitemaps.py.
New videos added by hand to Q&A pages are picked up automatically because the catalog reads data/qa_videos.json (run qa_videos.py extract first).

## Revive ad zones
Header zone 31833 (after the header), mid-page zone 31835 (after the answer on Q&A pages; at the ~50% text point elsewhere, via tools/revive_mid.py; single-grid hub pages are skipped) and footer zone 31834 (before the footer) are inserted after the site header on every page by `python3 -I tools/add_revive.py` (idempotent; marker `<!-- revive-header -->`). build_qa.py already emits it. Run add_revive.py after build_video_pages.py and after any page-generating script; add further zones in that script.

## Home subject bar
The scrolling subject chips in the sticky home-page header (all Q&A categories, most answers first) are generated by `python3 -I tools/build_subject_bar.py` from the category cells in qa/index.html. Re-run after a Q&A rebuild.
